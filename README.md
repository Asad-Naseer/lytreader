# Lytreader

Lightweight book reading app that works primarily in the browser.

Made with Vite + React + Typescript. 
Uses bun as package manager.

Uses IndexedDB to store Bookmarks and Reading positions.

Syncing to Cloud is enabled through Dropbox API. Since I made this app for myself and am going to keep the Dropbox API in development for the foreseeable future, the limit on the API is only 500 users. When users sync to or from the cloud, everything, including Books are saved into and retrieved from a single file.
